# Monitoring Stack (Prometheus & Grafana)
## Виконав: Капустяк Роман (ШІ-33) [repo link](https://github.com/RomanKapustiak/open-data-ai-analytics)

Цей модуль реалізує систему моніторингу для проєкту "Open Data AI Analytics", розгорнутого в Azure.

## Архітектура моніторингу
Система складається з чотирьох сервісів:
- **Prometheus**: Збирає та зберігає метрики.
- **Grafana**: Візуалізує дані на дашбордах.
- **Node Exporter**: Експортує метрики Linux-сервера.
- **cAdvisor**: Аналізує ресурси Docker-контейнерів.

## Розгортання
Моніторинг розгортається автоматично разом з основною інфраструктурою через Terraform та cloud-init.

Команда для ручного запуску:
```bash
docker compose -f monitoring/docker-compose.monitoring.yml up -d
```

## Відкриті порти
- 8000: Веб-інтерфейс застосунку та /metrics.
- 3000: Веб-інтерфейс Grafana (відкрито в Azure NSG).
- 9090: Інтерфейс Prometheus (внутрішній).

## Як відкрити Grafana
1. Отримайте IP-адресу вашої VM (terraform output vm_public_ip_address).
2. Перейдіть у браузері за адресою: http://<VM_IP>:3000.
3. Використовуйте стандартний логін admin / admin (система попросить змінити пароль при першому вході).  

## Налаштовані панелі
На головному дашборді представлені:
1. CPU Usage: Відсоток завантаження процесора хоста.  
2. Memory Usage: Об'єм використаної оперативної пам'яті.  
3. App Requests: Лічильник вхідних запитів до веб-сервісу.
